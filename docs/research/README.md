## What we learned

- The reports are careful and cite a literal quote and URL for every claim. They are safe to use as pointers.
- They found little because the parties have published little. More searching will not fix that; a published programme will.
- The Compromís report could not open frontvalencia.org. A direct read of that page on the same day found two more positions (Q05, Q17). So always read the official site directly as well.
- Each report also lists other concrete measures (Part B). Use them when choosing statements 21 to 30.
