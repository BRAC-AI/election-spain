# Image brief

One illustration per statement, plus one for the start screen. The app already has the slot: send me the files and I switch them on.

## Rules for every image

- Style: BRACAI watercolour editorial. Soft edges, white paper showing, teal `#0097b2` and deep blue gray `#2d3945` as the only strong colours.
- Format: 4:3, 1200 x 900 px, WebP, under 120 KB. Subject centred; the card crops a little on small phones.
- File name: `img/q01.webp` to `img/q20.webp`, and `img/start.webp`.
- Neutral: show the thing the statement is about, never a result of the policy. No winners, no victims.
- No people's faces, no party colours used as signals (avoid red, blue, green, purple and orange as accents), no flags, no text, no logos.
- Same light, same horizon height, same amount of white space across the set, so no topic looks more serious than another.
- Test: if a viewer can guess which answer the image prefers, redo it.

## Start screen

`img/start.webp`: a ballot box seen from above with blank folded papers around it. Calm, inviting, no colours on the papers.
