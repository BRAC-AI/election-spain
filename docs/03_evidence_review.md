# Evidence review sheet

One block per party. One row per statement. Nothing reaches `data/stances.json` without the last three columns filled by a human.

Stance values: `support`, `oppose`, `conditional`, `insufficient_evidence`.

Rules for the reader:
1. Read the passage in context. A keyword hit is not a stance.
2. Silence is `insufficient_evidence`. So is a vague goal with no measure.
3. A stance from press, speeches or votes does not count. Programme only.
4. If two passages disagree, code `conditional` and note both pages.
5. The quote must be exact and in the original language.
